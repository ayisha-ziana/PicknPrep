-- PicknPrep --

A Python-based food ordering system developed for a Grade 12 project.

-- Features:

- Browse a menu of main dishes and beverages
- Select items for an order
- Create and save custom recipes
- Update item quantities
- Generate a final bill

-- Technologies Used:

- Python
- MySQL
- mysql.connector for database connectivity

-- Project Status:

This repository contains the Python source code and ASCII art logo from the original project. The original MySQL database setup and table data are not currently available, so the program is not yet runnable as a complete application.

-- Files:

- picknprep-changed.py — Python source code
- logo.txt — Text-based logo displayed on the welcome screen
